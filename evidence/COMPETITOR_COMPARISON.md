# CRTI — twelve-platform comparison

**Evidence checked:** 2026-11-25 (UTC/CH date). **Status:** 12/12 named rows have a disposition. No product was tested with a paid account. This is a comparison of published evidence, not a ranking or an independent product test. Product details and plan names can change; sources were accessed on the date above.

The measures below are different and must not be treated as interchangeable:

- **Context occupancy:** tokens or capacity currently in a conversation/session and its limit.
- **Allowance:** an account, plan, team or organization quota over a defined period.
- **Token usage:** reported input/output/cache counts for a request, task or session.
- **Monetary cost:** billed or estimated currency. An estimate is not an invoice.
- **ACUs:** Devin Agent Compute Units. They are not raw token counts.
- **Cache:** cached input token counts or savings, when the product and authentication mode expose them.
- **Persistence/recovery:** stored task or conversation history, snapshots, and the ability to resume. A source-control snapshot is not a conversation backup.

## Source status and limitations

- All 12 required names are present and dispositioned. Codex is an internal comparator, not a competitor.
- No rows use direct paid product testing. Sources are public documentation, API references, or clearly labelled vendor/partner material.
- “Unknown” is not treated as “absent”. Where sources support only API request counts, CLI session state, allowance, ACUs or stored history, the table states that scope and does not equate it with active context occupancy or complete monetary accounting.
- Evidence is a dated public-source snapshot, not proof that a feature is enabled for every plan, account, region or client version. No cross-product capability ranking is implied.
